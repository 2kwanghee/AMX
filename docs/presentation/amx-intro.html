How it works

클릭 한 번 뒤에 일어나는 일

관리자
"계정 A를 서버 1에 배정"
ams-server
장부 기록 · 명령 서명
서버 1
에이전트 + tsamx
1웹에서 배정을 클릭하면, 중앙 장부에 기록되고 명령이 만들어집니다.
2로그인 정보는 암호화된 채로 보안 채널을 타고 서버 1로 내려갑니다.
3에이전트가 tsamx에 등록하면, 그 서버의 Claude Code가 곧바로 계정 A로 동작합니다.
4계정 A의 한도가 95%에 닿으면 tsamx가 자동으로 계정 B로 전환합니다.
5전환 사실이 중앙에 보고되고, 관제 화면이 갱신됩니다. 사람이 한 일은 처음의 클릭 한 번입니다.
Security

로그인 정보를 다루는 시스템의 기본기

ENVELOPE ENCRYPTION
저장은 이중 암호화
계정 로그인 정보는 중앙 DB에도, 각 서버 디스크에도 암호화된 상태로만 존재합니다.
ED25519 SIGNING
모든 명령에 서명
에이전트는 중앙 서버의 서명이 검증된 명령만 실행합니다. 위조 명령이 끼어들 자리가 없습니다.
BFF LAYER
브라우저에는 아무것도
관리 화면은 중계층을 거쳐 통신합니다. 서버 주소도 토큰도 브라우저에 노출되지 않습니다.
RUNNER GUARD
요금이 엉키지 않게
계정을 교체하는 순간의 실행을 막아, 사용량이 엉뚱한 계정에 찍히는 사고를 차단합니다.

관리자 권한도 전체 관리자와 그룹별 관리자로 나뉩니다.

Observability

이제 실측하고, 알리고, 남깁니다

LANGFUSE METRICS
토큰을 추정 아닌 실측으로
사내에 띄운 Langfuse로 러너 세션을 흘려보내, 계정·모델별 토큰 소비를 실제 수치로 사용량 탭에 보여줍니다.
ALERTS · WEBHOOK
경보 13종, 콘솔 밖으로도
HMAC 서명 웹훅으로 사내 채널까지 내보냅니다. 비용 급증·수집 중단·지연은 임계값 경보로 미리 잡습니다.
DANGER GUARD
위험한 명령은 실행 전에
러너의 PreToolUse 훅이 위험한 Bash를 가로채, 민감부를 마스킹해 통보하고 critical 경보를 엽니다.
AUDIT TRAIL
누가 무엇을 바꿨는지
관리자의 변경성 액션은 전부 감사 로그로 남습니다. 대상 그룹을 지워도 이력은 사라지지 않습니다.

관측·통보 계층은 켜지 않은 서버에선 동작이 완전히 같습니다.

Hardening

조용히 사고를 막는 장치들

SELF-HEALING RECALL
회수 실패도 스스로 회복
회수가 한 번에 끝나지 않아도 정해진 상한까지 스스로 재시도해, 장부와 서버의 실제 상태를 다시 맞춥니다.
BILLING WATERMARK
집계가 앞서 나가지 않게
서버 시계가 앞으로 튀는 걸 감지하면 집계 커서를 되감아 다시 계산합니다. 잘못 배분된 요금이 남지 않습니다.
RETENTION
남길 것과 지울 것
다 쓴 계정 스냅샷·끊긴 배정은 보존 기간에 맞춰 정리하고, 감사 로그는 기본으로 무기한 남깁니다.
SHARED PC PROFILE
한 PC, 두 역할
개인 작업과 러너가 한 대를 나눠 쓸 때, 러너는 별도 프로필로 amx 명령으로 띄웁니다.
